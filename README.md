# الرحيق المختوم: شرح تفاعلي

شرح مصوّر وتفاعلي لكتاب «الرحيق المختوم» للشيخ صفي الرحمن المباركفوري، في 32 فصلًا على تقسيم المؤلف: خرائط ومشاهد وأشجار نسب وخطوط زمنية واختبارات.

**الموقع:** https://fahalabi.github.io/Al-Raheeq-al-makhtum/

---

An illustrated, interactive Arabic walkthrough of *Ar-Raheeq Al-Makhtum* (The Sealed Nectar) by Safiur Rahman al-Mubarakpuri, chapter by chapter, with maps, scenes, family trees, timelines and quizzes.

The whole site is one self-contained `index.html`. `og.png` is the link preview image.
